Focusly: Design System Documentation
Version: 1.0
Last Updated: April 25, 2026
Design Philosophy: Clean, minimal, focus-driven learning experience
1. Design Principles
Core Values
1. Clarity First - Remove cognitive friction, information should be instantly scannable
2. Progressive Disclosure - Show what matters now, hide complexity until needed
3. Encouraging, Not Overwhelming - Celebrate progress, gentle on mistakes
4. Timeless Aesthetic - Modern but not trendy, won't feel dated in 2 years
5. Performance-Minded - Every design decision considers load time and smoothness

Usage Guidelines

Contrast ratio - Minimum 4.5:1 for body text, 7:1 for headings (WCAG AA)

7. Motion & Animation
Timing Functions
Duration Standards
Animation Principles
Micro-interactions:
css
ease-out: cubic-bezier(0, 0, 0.2, 1) ← Default
ease-in: cubic-bezier(0.4, 0, 1, 1)
ease-in-out: cubic-bezier(0.4, 0, 0.2, 1)
snappy: cubic-bezier(0.2, 0, 0, 1)
instant: 100ms (hover states)
fast: 200ms (button clicks, color changes)
normal: 300ms (card movements, fades)
slow: 500ms (page transitions, reveals)
lazy: 800ms (celebration animations)
Button hover: Scale 1.02, 200ms
Card hover: TranslateY -2px, shadow increase, 250ms
Input focus: Border color + subtle glow, 200ms
Toggle switch: Background + position, 200ms
Page Transitions:
Fade in + Slide up 8px, 400ms ease-out
Sidebar slide in/out: 300ms snappy
Modal: Backdrop fade 200ms, content scale 0.95→1 + fade, 250ms
Loading States:
Skeleton screens: Shimmer effect, 1.5s loop
Spinner: Rotate 360deg, 1s linear infinite
Progress bar: Smooth width transition, 300ms
Celebration Moments:
Correct answer: Confetti burst, scale pulse
Level up: Badge bounce in, glow effect
Streak milestone: Number count up + color shift
Animation Guidelines
Reduce motion: Respect prefers-reduced-motion , disable non-essential animations
Performance: Use transform and opacity only (GPU accelerated)
Purpose: Every animation should have purpose, not decoration

10. Responsive Design
Mobile Adaptations (< 768px)
Layout:
Sidebar becomes bottom navigation (4-5 items)
Collapse secondary navigation into hamburger menu
Single column layout
Increased touch targets (minimum 44x44px)
Typography:
Slightly smaller headings (see type scale)
Maintain body text at 15px for readability
Increase line-height by 0.1 for smaller screens
Components:
Full-width buttons on mobile
Cards stack vertically
Reduce padding: 16px instead of 24px
Simplify complex tables → card-based list view
Interactions:
Swipe gestures for navigation
Bottom sheets instead of modals
Sticky CTAs at bottom of screen
11. Accessibility Standards
WCAG AA Compliance
Color Contrast:
Text: Minimum 4.5:1 ratio
Large text (18px+): Minimum 3:1 ratio
UI components: Minimum 3:1 ratio
Focus Indicators:
Keyboard Navigation:
Tab order follows visual hierarchy
Skip to main content link
All interactive elements accessible via keyboard
Visible focus states on all focusable elements
Screen Readers:
Semantic HTML ( <nav> , <main> , <article> )
ARIA labels for icon-only buttons
Alt text for all images
Live regions for dynamic content updates
Other:
Captions for video content
Transcripts for audio
Form labels always visible (no placeholder-only)
Error messages clearly associated with inputs
