# Focusly - AI-Powered Learning Platform

Focusly is a premium full-stack study companion optimized for smart students. It utilizes predictive spaced repetition and AI models to simplify subject masteries.

## 🚀 Features
* **Smart Notes**: Automated AI synthesis.
* **Learning DNA**: Visual metrics.

## 🛠️ Stack
* **Frontend**: Next.js 15 + Tailwind CSS
* **Backend**: Spring Boot + H2 Data Stores

## ⚙️ Operations
```powershell
npm run dev
```
