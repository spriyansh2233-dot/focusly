# 🚀 Focusly - AI-Powered Learning Platform

Focusly is a premium full-stack study companion optimized for smart students. It utilizes predictive spaced repetition and state-of-the-art AI models to simplify subject mastery and maximize memory retention.

![Focusly Banner](https://images.unsplash.com/photo-1501504905252-473c47e087f8?auto=format&fit=crop&q=80&w=1200)

## ✨ Core Features

*   **🧠 Smart Notes**: Automated AI synthesis and multi-format parsing (PDF, Word) for instant learning assets.
-   **🧬 Learning DNA**: Advanced visual metrics and memory decay tracking based on the Forgetting Curve.
-   **🎭 Mood Modes**: Adaptive study environments that shift based on your cognitive load and emotional state.
-   **🤖 AI Tutor**: A 24/7 intelligent companion for deep conceptual clarification and personalized guidance.

## 🛠️ Technology Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | Next.js 16 (App Router) + Tailwind CSS 4 + Framer Motion |
| **Backend** | Java 21 + Spring Boot 3.4 + Spring Security |
| **Database** | PostgreSQL + H2 (Local Development) |
| **AI Engine** | Google Gemini 1.5 Flash + Structured Prompting |
| **Auth** | JWT (Stateless Authentication) |

## ⚙️ Operations

### Quick Start (Frontend)
```powershell
cd frontend
npm install
npm run dev
```

### Quick Start (Backend)
```powershell
cd backend
./mvnw spring-boot:run
```

## 📖 System Architecture

Focusly follows a **Distributed Micro-Stack** architecture:
- **Client**: Bleeding-edge React 19 / Next.js 16 for sub-second page transitions.
- **API**: Industrial-strength Spring Boot for high-concurrency background processing.
- **AI Pipeline**: Asynchronous Gemini integration for text extraction and concept mapping.
